Controls

What each control does

Rows / Cols
Grid size. More = smaller circles and tighter pattern; fewer = bigger circles.
Fill density
How much of the grid is filled (%). Higher = more connected blobs.
Margin %
Space around the grid. Higher = smaller drawing area, more border.
Background
Canvas background color. Does not change the composition.
Dot 1–5
Colors for each layer. Changing these only changes color; the pattern stays the same.
Stroke weight
Outline thickness on shapes. 0 = no outline.
Random seed
Number that determines the pattern. Same seed = same composition every time.

Animation tab

The composition never changes here — the charge travels through it. Each blob gets a start and an end, so the movement runs along the lines you made instead of pulsing everything at once. The Composition tab always shows the clean still; this tab shows it charged.

Playback
Play / pause. Paused freezes the current frame, so you can tune it and export the exact still you want.
Style
Current = a charge running the lines. Static = noisy interference. Storm = violent, with dropouts. Comet chase = a bright head with a fading tail. Breathe = slow swell.
Speed
How fast the charge travels.
Flow spread
How many pulses fit along a blob at once. Low = one big wave; high = many tight bands chasing each other.
Desync
Scatters each particle's timing so nothing moves in unison.
Reverse flow
Runs the charge back the other way through the structure.
Pulse
How much each particle swells as the charge reaches it.
Jitter
Positional shake — the static/electricity feel.
Flicker
How dark particles go between pulses. High = blinking out.
Bleed flow
How far the connections pinch to thin filaments between pulses, swelling back as the charge passes.
Sparks
Size and rate of the bright dots riding along the connections.
Crackle
High-frequency noise on everything. Sharpens pulses and adds dropouts.
Trails
How long each frame smears behind the next. High = long light trails.
Glow / Spark color
Bloom on charged particles and the color they flash toward.

Export MP4 records the canvas, so animations can be saved as video.
