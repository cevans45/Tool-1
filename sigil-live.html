Sigil Live

Sigil Live

Draw a sigil, set type, then bake both into a distance field that the GPU animates. The live pass is a single fragment shader, so what you tune here is what ships to Resolume.

Draw

Click and drag to draw. Hold Shift to constrain to an axis. Space clears, ⌘Z undoes. Mirror and marker change the character of the stroke.

Type

Type into the text field and drop a .ttf/.otf/.woff onto the canvas to use your own font. Text and sigil bake into the same field but stay separately controllable.

Live

The charge travels along the path in the order you drew it, and through text in character order. Everything else is post on top of the distance field.

Output

Open Output Window gives you a chromeless render window to capture or share. Export FFGL Bundle writes the atlas, parameters and shader source for the plugin build.
