Controls

What each control does

Custom fonts are loaded in memory for this page only. Drop .ttf, .otf, or .woff on the canvas.

Text
What gets drawn on the canvas. Disabled while Show Alphabet is on.
Show Alphabet
Replaces your text with A–Z (capital letters) for specimen-style layouts.
Font size
Scale of the type on the canvas.
Spacing
Letter spacing (tracking).
Line height
Vertical rhythm between lines when you use multiple lines of text.
Align (L / C / R)
Horizontal alignment of the text block.
Font
The hint shows the active font filename after a drop. Reset font goes back to the default. Mash fonts assigns each character a random slot (font + look + particle mode).
Mode
How letters are rebuilt with particles: circles, squares, grid, etc., or None for plain type.
Render (Fill / Stroke)
Whether the letter effect is filled or outlined (per Typo’s render pipeline).
Outline
Stroke weight when using stroke-style rendering.
Density
How many particles / samples build each letter.
Scale
Size of the particle pattern relative to the letters.
Uniform
How even vs varied the particle placement is.
Jitter
Random positional shake of particles.
Drift
Slow wandering motion of the field; Reset zeroes drift state.
Pause
Stops or resumes motion so you can inspect a frame.
Ink / Background
Foreground ink and canvas background color.
Export (bottom of panel)
SVG, PNG, IMG (JPEG), and MP4 (~10s of the main canvas when your browser supports recording).
