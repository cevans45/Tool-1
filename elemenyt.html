Controls

What each control does

Trace images sit behind your drawing for reference only—they are not included in PNG or SVG export.

Sketch / Generate / Animate
Sketch — draw by hand. Generate — procedural random paths. Animate — bring the drawing to life; see the animation list below.
Upload image
Loads a reference behind the canvas for tracing.
Image opacity
How visible the trace image is; 0 is invisible.
Image scale
100% fits the image within the canvas; lower zooms out, higher zooms in.
Generate
Runs a new random path in Generate mode.
Draw time
Higher values produce longer, denser generated paths.
DRAW / ERASE
DRAW adds ink. ERASE removes with a soft cut (destination-out). Sketch tab only.
Mirror
Duplicates strokes across the vertical and/or horizontal axis from the canvas center. The same two toggles sit in the Animation panel, so you can flip them while a composition is moving — the reflections pick up the motion too.
Stroke size
Brush thickness for segments and marker textures.
Sticky / Sticky dist
Organic growth along the stroke; strength 0 is off. Distance controls how far branches reach from the path.
Taper ends
Fades stroke width at the start and end of each pen-down segment.
Marker
Texture along each stroke: none, jagged line, sprinkle, grid, grain, or inkblot.
Marker preview
Live preview of the current marker at your stroke size.
Fill
On — solid interior uses Fill color. Off — jagged outline look using Ink and Outline colors.
Ink / Outline / Fill color
Ink — stroke when Fill is off. Outline — outer edge of the jagged filter. Fill — interior when Fill is on.
Background
Color behind the sketch and default export background.
Outline thickness
Thickness of the jagged outline ring (SVG morphology radius).
Export (bottom of panel)
Export SVG / PNG / IMG — PNG uses the same composite as before (trace image excluded). IMG is JPEG.
Keyboard
Space — clear canvas. ⌘Z / Ctrl+Z — undo last stroke. Shift while drawing — constrain each step to horizontal or vertical from the previous point.

Animate tab

A charge travels along the path you drew. It bends the line, pumps its thickness and runs the ink hot as it passes, so the outline itself moves rather than only the particles around it. Your saved drawing is untouched — leaving the tab restores the plain still.

Pause / Play
Freezes on the current frame, so you can tune it and export the exact still you want.
New path
Rolls a fresh generated composition without leaving the tab.
Style
Current — a charge running the lines. Static — noisy interference. Storm — violent, with dropouts. Comet chase — a bright head with a fading tail. Breathe — slow swell.
Motion
What the charge does to the form. Style sets the charge, Motion sets the movement, so any pairing works. The Hit and Broken groups are driven by impulses that land at uneven times and decay unevenly, which is what keeps them from reading as water.

Whip — a crack travels through the drawing. Nothing moves ahead of the front, everything snaps the instant it arrives, then drags out in a long tail behind.
Stomp — lopsided chunks get slammed sideways and spring back past their resting place, wobbling as they settle.
Jolt — the whole form takes the hit at once, but the far end hears about it late, so it whips instead of sliding as one block.
Glitch — chunks tear loose in any direction, hold for an uneven stretch, then snap somewhere else.
Stutter — dead still, then a chunk teleports to a spot on a coarse grid, then dead still again. No travel between poses at all.
Shatter — every point has its own escape direction, so impulses blast the pieces out and they drift back into place.
Tendril — each chunk wanders on its own clock at its own rate, so neighbours disagree and nothing sweeps through as one wave.
Ratchet — quantised in time and distance; the form lurches between held poses.
Flow — the liquid one: smooth travelling waves, the line bends as a whole.
Slither — lunges forward along its own course then creeps back, so it crawls in a direction.
Coil — winds the line into a corkscrew that screws along its own course.
Burst — rings punching out from the canvas centre and sagging back in.
Swirl — twists about the canvas centre, winding up fast and unwinding slowly.
Speed
How fast the charge travels along the path.
Flow spread
How many pulses fit along the drawing at once. Low = one sweep; high = many tight bands chasing each other.
Desync
Scatters timing per spot so nothing moves in unison.
Reverse flow
Runs the charge back the other way through the drawing.
Warp
How far the form is displaced from the course you drew. This is what makes the outline travel and reshape; 0 holds the exact drawn form for every Motion.
Swell
Pumps stroke thickness with the charge — fat where it passes, thinner behind it — so the silhouette breathes.
Charge
How hot the ink runs where the charge sits, flashing toward the spark color.
Bleed reach
How far ink growth reaches across gaps as the charge arrives, retracting behind it. Uses Sticky dist to decide which gaps can bridge.
Jitter
Shake on the growth — the static / electricity feel.
Flicker
How much blinks out between pulses.
Sparks
Number and size of bright dots running along the lines.
Crackle
High-frequency noise on everything. Sharpens pulses and adds dropouts. Also drives how often impulses land and how fast the stepped motions snap between poses — turn it up for a constant barrage.
Trails
How long each frame smears behind the next. High = long light trails.
Glow / Spark color
Bloom on charged areas and the color they flash toward.

Export MP4 records about ten seconds of the canvas, so a run can be saved as video. Pause first if you want a still instead.
