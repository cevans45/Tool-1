Controls

What each control does

DRAW / ERASE
DRAW draws; ERASE erases using destination-out.
Marker
Line = jagged segments. Sprinkle/Grid/Grain = alternate scratch textures.
Fill
If ON, uses “Fill color” for ink + outline coloring.
Outline thickness
Controls the jagged-edge filter dilation radius.
Undo
Cmd/Ctrl+Z undoes the last stroke.
